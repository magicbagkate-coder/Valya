# doc-readme-scripts

**Level:** Review. The linter cannot check this rule.

**Allowed:** One README line for each new npm script. The line gives the command and its purpose. Do not use anything else.

**Reason:** A new person finds each command in one place. A reader forgets a script that has no description.

**Good**
```md
- `npm run lint:docs` - Checks the documentation text with Vale.
```
