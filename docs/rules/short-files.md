# short-files

**Level:** Error. The build stops.

**Allowed:** A file of 250 lines or fewer. Do not count blank lines and comments. Do not use anything else.

**Reason:** A long file usually has more than one task. The limit makes you split the file along a real boundary.

**Exception:** Keep a file of less than 50 lines that has one task as it is. Test files have no limit.
