# doc-existing-files

**Level:** Review. The linter cannot check this rule.

**Allowed:** New text in an existing file. A new rule file in `docs/rules/` with a link in the `README.md` index. A new Markdown file when the task asks for it. Do not use anything else.

**Reason:** Extra files become old and are hard to find. One place for each topic keeps the documentation correct.
